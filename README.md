# MR91 Wealth

ثروت MR91 یک برنامه‌ی اندرویدی و **کاملاً آفلاین** برای مدیریت مالی شخصی است. همه‌ی داده‌ها روی همان دستگاه می‌مانند؛ برنامه به اینترنت، حساب کاربری یا سرویس ابری نیاز ندارد و هیچ فونت، تصویر یا کتابخانه‌ای از شبکه دانلود نمی‌کند.

## واحد پول و دقت محاسبات

- واحد پول در کل برنامه **تومان** است. ریال به‌صورت خودکار تبدیل نمی‌شود.
- مبالغ به‌صورت عدد صحیح (Long) ذخیره می‌شوند. اعشار مجاز نیست و از float برای محاسبات پول استفاده نمی‌شود.
- شمارش موجودی در صفحه‌ی اصلی با انیمیشن انجام می‌شود، اما مقدار نهایی همیشه دقیقاً همان عدد ذخیره‌شده است.

## فاصله از لبه‌ی گوشی

- محتوا **۱ سانتی‌متر** پایین‌تر از نوار بالای گوشی شروع می‌شود.
- نوار ناوبری شناور **۱ سانتی‌متر** بالاتر از نوار پایین گوشی قرار دارد.
- این مقدار در `ONE_CENTIMETER` (`ui/Motion.kt`) تعریف شده است. هر ۱ سانتی‌متر برابر است با ۱۶۰ / ۲٫۵۴ dp، یعنی حدود ۶۳ dp، و این مقدار روی همه‌ی گوشی‌ها اندازه‌ی فیزیکی یکسانی دارد.

## هویت برند

- نشان و رنگ‌ها از لوگوی رسمی استخراج شده‌اند؛ قوانین کامل در `brand/GUIDELINES.md` و مقادیر در `brand/tokens.json` هستند.
- آیکون لانچر سرمه‌ای و فیروزه‌ای روی سفید است و نسخه‌ی تک‌رنگ برای آیکون تم‌دار اندروید ۱۳ دارد.
- رنگ پیش‌فرض برنامه «آبی MR91» (فیروزه‌ای برند) است.

## ظاهر و انیمیشن

- پس‌زمینه‌ی متحرک با لکه‌های رنگی نرم که در حال حرکت آهسته‌اند.
- کارت موجودی با گرادیان و شمارش عدد.
- نمودار دونات برای سهم دسته‌ها و نمودار میله‌ای برای ۶ ماه اخیر، هر دو با انیمیشن ورود.
- کارت‌ها با ورود پلکانی (stagger) و فشردن نرم با فنر.
- جابه‌جایی تب‌ها با انیمیشن افقی و نوار ناوبری شناور با نشانگر متحرک.
- پیش‌نهادی برای همه‌ی انیمیشن‌ها: اگر در تنظیمات سیستم «حذف انیمیشن‌ها» (Animator duration scale = 0) فعال باشد، همه‌ی حرکت‌ها غیرفعال می‌شوند.
- رنگ اصلی قابل انتخاب است: فیروزه‌ای، آبی نئونی، نیلی، کهربایی یا گلی. روی اندروید ۱۲ به بالا، رنگ‌های پویای سیستم هم قابل فعال‌سازی است.

## قابلیت‌ها

- **تراکنش‌ها**: درآمد، هزینه و انتقال بین حساب‌ها. جستجو در شرح و دسته‌بندی، فیلتر نوع، گروه‌بندی بر اساس روز شمسی. ویرایش، حذف به سطل زباله و بازگردانی با Undo. هشدار تراکنش تکراری.
- **حساب‌ها و اهداف پس‌انداز**: هر حساب موجودی، نوع و رنگ خودش را دارد. برای هر حساب می‌توان هدف پس‌انداز تعریف کرد و پیشرفت آن با حلقه‌ی درصدی نشان داده می‌شود. حساب‌ها بایگانی می‌شوند (با امکان برگشت).
- **داشبورد**: موجودی کل، درآمد و هزینه برای امروز، این هفته، این ماه، امسال یا همه. بینش‌ها شامل میانگین روزانه، بیشترین دسته‌ی هزینه و مقایسه با دوره‌ی قبل. نمودار دونات سهم دسته‌ها.
- **بودجه‌ی ماهانه**: برای یک دسته یا کل هزینه‌ها، با مصرف، مانده، درصد و هشدار نزدیک شدن به سقف.
- **دنگ‌ودونگ**: گروه، اعضا، هزینه‌ی گروهی با تقسیم مساوی (باقی‌مانده بدون خطای اعشاری پخش می‌شود)، فهرست «چه کسی به چه کسی بدهکار است» با کمترین تعداد پرداخت، ثبت پرداخت و حذف هزینه با Undo.
- **پشتیبان و خروجی**: پشتیبان JSON نسخه‌دار با اعتبارسنجی کامل و بازیابی بعد از تأیید. خروجی CSV با BOM برای اکسل (فرمول‌های احتمالی در اکسل خنثی می‌شوند).
- **ظاهر**: حالت روشن، تیره یا سیستم؛ ارقام فارسی یا لاتین؛ چیدمان کامل راست‌به‌چپ.

## محدودیت‌های فعلی

- برنامه‌ی انگلیسی ندارد و متن‌ها هنوز در کد نوشته شده‌اند، نه در `strings.xml`.
- فونت سفارشی بسته‌بندی نشده است تا برنامه کاملاً آفلاین و سبک بماند؛ متن‌ها با فونت سیستم نمایش داده می‌شوند.
- بودجه‌ی تکرارشونده و انتقال خودکار بودجه به ماه بعد وجود ندارد.
- تقسیم نابرابر هزینه‌ی گروهی وجود ندارد؛ فقط تقسیم مساوی است.
- فایل پشتیبان رمزنگاری نمی‌شود.
- بک‌آپ خودکار سیستم برای این برنامه غیرفعال است؛ داده‌ها فقط با خروجی صریح کاربر جابه‌جا می‌شوند.
- انیمیشن‌ها و چیدمان روی گوشی واقعی هنوز بصری تأیید نشده‌اند.

## ساخت و تست

نیازمندی‌ها: JDK 17، Android SDK با Platform 35 و Build-Tools مناسب، و Gradle 8.9.

```bash
# یک‌بار، برای تولید Gradle Wrapper واقعی (فایل gradle-wrapper.jar در این مخزن نیست)
gradle wrapper --gradle-version 8.9

./gradlew :app:testDebugUnitTest
./gradlew :app:assembleDebug
```

تست‌های واحد (JVM) شامل پول و مرزهای آن، تقویم شمسی روی همه‌ی روزهای ۲۰۰۰ تا ۲۰۴۵، بازه‌های زمانی و دوره‌ی قبل، منطق دفتر تراکنش، بودجه، تقسیم و تسویه، خروجی CSV و کدک پشتیبان با رد فایل‌های خراب هستند.

## Release امضاشده

Release فقط وقتی امضا می‌شود که متغیرهای `MR91_KEYSTORE_PATH`، `MR91_KEYSTORE_PASSWORD`، `MR91_KEY_ALIAS` و `MR91_KEY_PASSWORD` تنظیم شده باشند. در GitHub Actions این مقادیر از Secrets خوانده می‌شوند. keystore و رمزها هرگز داخل مخزن commit نمی‌شوند.

## ساختار کد

- `domain/` منطق خالص بدون وابستگی به Android: پول، تقویم شمسی، بازه‌های زمانی، دفتر، بودجه، تسویه و CSV.
- `data/` Room با مهاجرت‌های ۱ تا ۳، DAOها، کدک پشتیبان و Repository.
- `ui/` ViewModel، کامپوننت‌های مشترک، حرکت (`Motion.kt`)، تم، و صفحه‌های Compose.

schemaهای Room در `app/schemas/` پس از اولین build تولید می‌شوند؛ آن‌ها را commit کنید تا مهاجرت‌ها با تست بررسی شوند.



## Gradle Wrapper recovery

This archive includes `gradlew`, `gradlew.bat`, and `gradle/wrapper/gradle-wrapper.properties` pinned to Gradle 8.9. The launcher downloads Gradle 8.9 on first run and caches it. It does not require the binary wrapper JAR. Internet access is needed on the first build.

The Android UI, navigation menu, color theme, motion, and the existing one-centimetre top/bottom spacing code were not changed while preparing this archive. This is a packaging repair only; it is not a claim that the APK has already compiled or passed device QA.
