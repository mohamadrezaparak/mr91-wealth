# MR91 Wealth — پروژه بومی اندروید

این پروژه یک اپلیکیشن مستقل Android با Java است؛ **WebView نیست** و برای اجرای بخش‌های اصلی به وب‌سایت Lovable نیاز ندارد.

## امکانات نسخه اولیه
- داشبورد موجودی کل و جمع درآمد/هزینه ثبت‌شده
- ثبت دستی درآمد و هزینه با دسته و تاریخ
- فهرست تراکنش‌ها و حذف تراکنش با لمس طولانی
- مدیریت اولیه حساب‌ها، اهداف پس‌انداز، بودجه و بدهی‌ها
- ذخیره خودکار محلی با SharedPreferences
- رابط فارسی راست‌به‌چپ، تم تیره و طراحی موبایل‌محور
- بدون دسترسی پیامک، اینترنت یا بانک

## باز کردن و ساخت APK
1. ZIP را استخراج کن.
2. Android Studio → Open → پوشه `MR91_Wealth_Final` را انتخاب کن.
3. اگر خواست، SDK Platform 35 و Gradle/Android plugin را نصب/دانلود کن و منتظر Sync بمان.
4. از منو Build → Build APK(s) را بزن.
5. خروجی معمولاً اینجاست: `app/build/outputs/apk/debug/app-debug.apk`

یا از Terminal ویندوز داخل پوشه پروژه، اگر Gradle Wrapper در Android Studio ساخته/تنظیم شده است، اجرا کن: `gradlew.bat assembleDebug`.

## وضعیت مهم
این نسخه یک **نسخه بومی اولیه و قابل توسعه** است، نه کپی کامل از تمام صفحات وب MR91 Wealth. تاریخ تراکنش‌ها را می‌توان دستی با قالب شمسی وارد کرد، اما تقویم ماهانهٔ شبکه‌ای و تبدیل خودکار شمسی/میلادی هنوز پیاده‌سازی نشده است. موجودی اولیهٔ حساب‌ها صفر است؛ ثبت و حذف تراکنش موجودی حساب پیش‌فرض را به‌روزرسانی می‌کند. خروجی پشتیبان از طریق منوی اشتراک‌گذاری اندروید ارسال می‌شود.

**وضعیت راستی‌آزمایی:** سورس از نظر ساختار متنی و توازن پرانتز/آکولاد بررسی شده است، اما در محیط فعلی Android SDK و Gradle اجرایی در دسترس نبود؛ بنابراین APK ساخته نشده و کامپایل/اجرای واقعی هنوز تأیید نشده است. برای ساخت، Android Studio و Android SDK سازگار لازم است.
